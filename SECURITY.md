# Security Policy

## Supported Versions

We actively maintain and provide security updates for the latest production release:

| Version | Supported          |
| ------- | ------------------ |
| 1.x.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We take the security and integrity of this website seriously. If you discover a potential security vulnerability or sensitive data exposure, please notify us privately.

**Please do NOT file a public GitHub issue for security vulnerabilities.**

### How to Report
1. Email your report to: `alisonferazzini.photo@gmail.com`
2. Include a detailed description of the vulnerability:
   - Steps to reproduce or proof-of-concept (PoC)
   - Impact assessment
   - Suggested mitigations (if available)

### Response Timeline
- **Initial Acknowledgement**: Within 48 hours.
- **Triage & Assessment**: Within 5 business days.
- **Fix & Public Advisory**: Coordinated responsibly once resolved.

Thank you for helping keep this project safe and secure!
